# Mezze Design — Visual Acceptance Evidence (D1 / D1.1)

Real screenshots of the running application (live Odoo 19 + PostgreSQL, DB `mezze_test`),
captured via Chrome automation. Filenames encode: surface · theme/mode · variant · viewport.
`staff-*` = staff workspaces (one shared shell). `cust-*` = customer-facing surfaces
(shared token system, no staff shell). See the D1.1 Final Report for the acceptance matrix.
