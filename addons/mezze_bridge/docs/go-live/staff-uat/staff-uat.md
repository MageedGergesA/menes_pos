# Staff UAT (P1 §24) — Representative + on-site plan
**Proven now (representative):** every role's permission boundary is enforced and regression-tested
(host seat, server fire, cashier pay, kitchen KDS, manager approve/refund/86). A user cannot perform
an action outside their role.
**On-site plan (the pilot itself):** trained staff run a real service day on the pilot host/hardware,
following runbooks/, recording any defect. This human UAT is intrinsically not a CI artifact.
**Classification:** Pilot supported with on-site verification.
