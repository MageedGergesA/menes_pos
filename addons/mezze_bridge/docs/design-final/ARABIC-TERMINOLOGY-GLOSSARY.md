# MEZZE — ARABIC TERMINOLOGY GLOSSARY (authoritative)

One approved Arabic term per product concept. Modern Standard Arabic, operational
register, intended to read naturally for restaurant staff in **Egypt, Saudi Arabia, the
UAE and Kuwait**. No Egyptian-only or Gulf-only slang, no government-formal phrasing, no
literal English syntax.

**This file is the tie-breaker.** If a string anywhere disagrees with a row here, the row wins.

---

## 1. The decisions that actually needed deciding

### `Register` — the selling workspace

| | |
|---|---|
| **Approved** | **نقطة البيع** |
| Rejected | ~~تسجيل~~ — means *registration / signing up*. This was the live defect found during final certification: with no explicit entry, "Register" fell through to an incidental core translation and an Arabic cashier read the sell screen as "Sign-up". |
| Rejected | ~~الكاشير~~ — that is the **person**, not the screen. Using it for both created a second collision (see below). |
| Why | `نقطة البيع` is the established industry term (POS) and is understood instantly by restaurant staff in every target market. It sits unambiguously beside الصالة / الطلبات / الحجوزات in the workspace navigation. |

### `Cashier` — the person / role

**الكاشير.** Kept for the human role (cashier sessions, cashier audit, "Cashier Web"
terminal). Because `Register` moved to نقطة البيع, الكاشير now names exactly one thing.

### `Park` vs `Hold` — two different suspensions

These are distinct product concepts and must not collapse onto one Arabic word:

| English | Approved | Scope |
|---|---|---|
| Park (an order) | **تعليق** / Parked → **معلّق** | the whole order is set aside so the register is free |
| Hold (a course) | **تأجيل** / Held → **مؤجل** | a later course is deliberately not sent to the kitchen yet |

### `Change` — money, not modification

**الباقي** (cash returned to the customer). Never ~~تغيير~~.

### `Fire` — kitchen, not combustion

**إرسال** (action) / Fired → **مُرسل** (state). Kept short for the kitchen display.

### `Seat` — a verb in reservations/waitlist

**إجلاس** (action) / Seated → **تم الإجلاس**. Not the noun "a seat".

### `Table` — one word only

**طاولة**. Rejected: ~~ترابيزة~~ (Egyptian colloquial), ~~منضدة~~ (stilted).

### Acronyms and names deliberately kept in Latin script

| Kept | Why |
|---|---|
| `Mezze` | product/brand name |
| `VIP` | internationally read marker, already used on reservation cards |
| `QR` | universal technical acronym |
| `POS` | only where it appears as a technical acronym in operator text |
| `Ctrl` / `F2` / `Esc` | physical key names in the keyboard legend |
| payment-provider names | proper nouns (Paymob, Adyen, InstaPay, …) |
| `T` + number (T5) | table **identifier** prefix, not a word |

## 3. Grammar rules applied

1. **Action vs state are never the same form.** `Cancel` (button) = إلغاء; `Cancelled`
   (state) = ملغي. `Notify` = إشعار; `Notified` = تم الإشعار. `Seat` = إجلاس;
   `Seated` = تم الإجلاس.
2. **Buttons stay short.** `Retry` → إعادة المحاولة, never a polite sentence.
3. **Business states keep one word each** so P3B's frozen status semantics stay visually
   distinguishable in Arabic exactly as they are in English.
4. **Placeholders are never translated or reordered away.** `%s` is preserved verbatim;
   Arabic may move it within the sentence, which is why several split sentences were
   consolidated into single `_t()` strings during this pass.
5. **Digits stay Latin.** Order numbers, table numbers, prices and timers must read
   identically in EN and AR for staff working across both.
6. **Identifiers are never translated** — UUIDs, POS references, table ids, API codes,
   provider names, URLs, emails, phone values, log/debug text.

## Selling workspace — one concept, three English labels

`Register`, `POS` and `Point of Sale` all name the SAME workspace and therefore all
translate to **نقطة البيع**. The prototype rail uses "POS"; the glossary and the
horizontal nav use "Register". This is a documented same-concept set in
`test_70_arabic_glossary_contract_c2`, not terminology drift.

It must still never be **تسجيل** (registration/sign-up) and never share a term with
**الكاشير** (the person).
