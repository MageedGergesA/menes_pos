# Mezze POS — Host / Front-of-House Guide

For the host managing the floor, reservations, and the waitlist.

## Floor plan

- The floor plan shows tables by area/room with live status (free, seated, ordering,
  bill requested).
- Tap a table to seat guests, which opens (or hands to a waiter) the table's order.
- Table layout is configured once in the Admin Console (areas, tables, seats).

## Reservations

- Create a reservation with guest name, party size, time, and contact.
- View upcoming reservations against the floor to plan seating.
- Seat a reservation to link it to a table when the party arrives.

## Waitlist

- Add walk-ins to the waitlist with party size and a contact.
- Work the list in order as tables free up; seat directly from the waitlist.

## Notes

- Reservation and guest contact details are customer PII stored on the Odoo partner —
  handle per `PRIVACY-DATA.md`.
- Live GPS/route features are not part of Mezze (delivery is manual dispatch) — this
  screen is about in-house seating only.
